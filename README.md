# echoes

> Not the voice — its echo.

Персонаж, который звучит одинаково и на первой реплике, и на сотой, и через неделю — без fine-tuning, только на промпте и памяти. Проверяем, долго ли держится эхо.

Каждое эхо описано своим **echo profile**, помнит прошлые встречи по **echo trail** и звучит через **Resonator**.

Эхо не входят в репозиторий: их создаёт пользователь. Своего персонажа можно описать в нескольких текстовых файлах, код трогать не нужно. Для начала есть шаблон.
